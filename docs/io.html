Reading and writing data

CSV files

DataFrame::fromCsv() reads delimited text the way readr’s read_csv() and read_delim() do. It takes a path (files ending in .gz are decompressed) or an open stream. DataFrame::fromCsvString() reads from a string.

readr’s options are named arguments in camelCase:

Option Default Meaning
types guess Column types, as a compact string or by name.
delimiter ',' The field separator.
na ['', 'NA'] Text that is read as NA.
colNames true true reads a header row, false names columns X1, X2, and so on, and a list gives the names.
select all Columns to keep, in this order.
skip 0 Lines to skip before the header.
nMax all The most rows to read.
comment '' Lines starting with this text are skipped.
quote '"' The quoting character.
trimWs true Trim spaces around unquoted values.
skipEmptyRows true Skip blank lines.
guessMax 1000 Rows used to guess types.
nameRepair 'unique' How to repair empty or duplicated names.
decimalMark, groupingMark '.', none Number formatting, as in readr’s locale(). 
$text = <<<'CSV'
    # exported 2024-06-01
    id;zip;score;visited
    1;02134;3,5;2024-05-01
    2;10001;-;2024-05-03
    3;94110;4,25;2024-05-04
    CSV;

$df = DataFrame::fromCsvString(
    $text,
    types: ['zip' => 'c'],
    delimiter: ';',
    na: ['-'],
    comment: '#',
    decimalMark: ',',
);

echo $df;
# A tibble: 3 × 4
     id zip   score visited   
  <int> <chr> <dbl> <date>    
1     1 02134  3.5  2024-05-01
2     2 10001 NA    2024-05-03
3     3 94110  4.25 2024-05-04

Column types

types accepts readr’s compact string, with one letter per column:

Letter Type
c string
i int
d float
n float, reading numbers with grouping marks and other characters
l bool
f factor
D date
T datetime
t string (phibble has no time-of-day type)
? guess
_ or - skip the column

types also accepts an array by column name. A value is a Type, a type name such as 'factor', or a letter. The key .default sets the type of every column not named.

$penguins = DataFrame::fromCsv('penguins.csv', types: 'ffddii_i');
echo $penguins->glimpse(), "\n";

$some = DataFrame::fromCsv('penguins.csv', types: ['species' => 'factor', '.default' => '_'], select: ['species']);
echo $some->glimpse();

Guessing

Without explicit types, phibble guesses each column from up to guessMax rows, sampled the way readr 2 samples them. A column is:

  • bool if every value is T, F, TRUE, FALSE, True, False, true, or false,
  • int if every value is a whole number (readr guesses double here),
  • float if every value is a number, including Inf and NaN,
  • date if every value is an ISO 8601 date,
  • datetime if every value is an ISO 8601 date and time,
  • string otherwise.

Numbers with leading zeros such as 007 stay strings, as in readr.

When a value cannot be parsed as its column’s type, or a row has the wrong number of fields, phibble still returns the data. The value becomes NA, and the read raises one E_USER_WARNING that lists the problems.

set_error_handler(function (int $level, string $message): bool {
    echo "Warning: {$message}\n";

    return true;
});

$df = DataFrame::fromCsvString("id,score\n1,2.5\n2,oops\n3\n", types: ['score' => 'double']);

echo $df;
Warning: One or more parsing issues: row 4: expected 2 columns, got 1; column 'score': 1 value could not be parsed as float.
# A tibble: 3 × 2
     id score
  <int> <dbl>
1     1   2.5
2     2  NA  
3     3  NA

Writing CSV

writeCsv($path) writes a file and toCsv() returns the text. The format follows readr’s write_csv(). Values are quoted only when needed, NA is written as NA, logicals as TRUE and FALSE, dates in ISO 8601, and datetimes in UTC with a Z. Factors are written as their labels, and list-columns throw.

$df = tribble(
    ['name', 'note', 'score', 'seen'],
    ['Ana', 'likes "quotes"', 1e5, true],
    ['Ben', 'a, b', null, false],
);

echo $df->toCsv();
name,note,score,seen
Ana,"likes ""quotes""",100000,TRUE
Ben,"a, b",NA,FALSE

The options are delimiter, na, append, colNames, quote ('needed', 'all', or 'none'), escape, and eol.

JSON

toJson() writes a list of records, and toJson('columns') writes an object of columns. NA is written as null and kept in every record. DataFrame::fromJson() reads either shape and detects which one it has.

$df = tibble(id: [1, 2], score: [2.5, null]);

echo $df->toJson(), "\n";
echo $df->toJson('columns'), "\n";

echo DataFrame::fromJson('{"id": [1, 2], "ok": [true, null]}');
[{"id":1,"score":2.5},{"id":2,"score":null}]
{"id":[1,2],"score":[2.5,null]}
# A tibble: 2 × 2
     id ok   
  <int> <lgl>
1     1 TRUE 
2     2 NA

Databases

DataFrame::fromPdo() runs a query with positional or named bindings and loads the result. Drivers that return numbers as text, as MySQL’s does, are handled by parsing all-text columns with the CSV guessing rules.

$pdo = new PDO('sqlite::memory:');
$pdo->exec('CREATE TABLE visits (id INTEGER, clinic TEXT, bp REAL, seen TEXT)');
$pdo->exec("INSERT INTO visits VALUES (1, 'north', 121.5, '2024-05-01'), (2, 'south', NULL, '2024-05-02'), (3, 'north', 133.0, '2024-05-02')");

$df = DataFrame::fromPdo($pdo, 'SELECT * FROM visits WHERE clinic = ?', ['north']);

echo $df;
# A tibble: 2 × 4
     id clinic    bp seen      
  <int> <chr>  <dbl> <date>    
1     1 north   122. 2024-05-01
2     3 north   133  2024-05-02

DataFrame::fromQuery() loads a query builder without depending on its library:

  • A Laravel query builder, Eloquent builder, or relation is read through toSql(), getBindings(), and its connection’s PDO object.
  • A Doctrine DBAL QueryBuilder is read through getSQL() and getParameters(). Pass a PDO or DBAL connection as the second argument to run the SQL through PDO. Without one, the builder runs the query itself.

To keep a query in the database and run verbs there, use a SQL table instead.

Laravel collections

DataFrame::fromCollection() reads any object with an all() or toArray() method, such as a Laravel Collection. The items may be arrays, objects, or Eloquent models. toCollection() returns an Illuminate\Support\Collection of row arrays and throws when Laravel is not installed.

// Any object with all() or toArray() works, such as a Laravel Collection
// of arrays or Eloquent models. This stand-in avoids a Laravel dependency.
$collection = new class
{
    public function all(): array
    {
        return [
            ['id' => 1, 'name' => 'Ana'],
            (object) ['id' => 2, 'name' => 'Ben'],
        ];
    }
};

echo DataFrame::fromCollection($collection);
# A tibble: 2 × 2
     id name 
  <int> <chr>
1     1 Ana  
2     2 Ben
