Read a CSV file into a typed table

Read readings.csv into a DataFrame, with one column’s type declared and the rest guessed:

date,station,temp_c,rain_mm,wind_kmh,windy
2024-03-01,north,7.5,0.0,12,FALSE
2024-03-01,south,9.1,1.2,31,TRUE
2024-03-02,north,6.8,NA,18,FALSE
2024-03-02,south,8.4,3.5,35,TRUE
2024-03-03,north,10.2,0.0,9,FALSE
2024-03-03,south,11.0,0.4,22,FALSE
use Phibble\DataFrame;

$readings = DataFrame::fromCsv(
    'readings.csv',
    types: ['station' => 'factor'],
);

echo $readings, "\n";
# A tibble: 6 × 6
  date       station temp_c rain_mm wind_kmh windy
  <date>     <fct>    <dbl>   <dbl>    <int> <lgl>
1 2024-03-01 north      7.5     0         12 FALSE
2 2024-03-01 south      9.1     1.2       31 TRUE 
3 2024-03-02 north      6.8    NA         18 FALSE
4 2024-03-02 south      8.4     3.5       35 TRUE 
5 2024-03-03 north     10.2     0          9 FALSE
6 2024-03-03 south     11       0.4       22 FALSE
  • Types are guessed from up to 1,000 sampled rows. Declare a type when those rows could mislead the guess.
  • Whole numbers become int, where readr’s read_csv() gives double.
  • types overrides a guess. Without it, station would be a string.
  • NA and empty fields become null.

Runnable script: read-a-csv.php. Run it from the directory that holds readings.csv.
