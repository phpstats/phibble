Getting started

Installation

composer require phpstats/phibble

phibble requires PHP 8.3, 8.4, or 8.5, and the mbstring and PDO extensions. These are optional:

Optional Enables
The phit extension, 0.4.0 or later Native CSV reading in fromCsv(), fromCsvChunked(), and csvChunks(). Results match the PHP reader.
The php_polars extension from phpolars PolarsTable and polars(), described in Backends.
illuminate/database The ->toDataFrame() and ->phibble() macros, described in Laravel. Laravel applications already have it.

The examples read public datasets, such as the Palmer penguins and nycflights13’s weather, by URL from the PHPstats datasets. Reading a URL needs PHP’s allow_url_fopen setting, which is on by default.

Imports

The examples on this page use these imports:

use Phibble\DataFrame;

use function Phibble\{tibble, tribble};
use function Phibble\Expr\{col, desc, mean, median, n};

Phibble\Expr has functions named min, max, sum, round, abs, log, floor, str_pad, str_split, str_replace, and a few others that share names with PHP built-ins. In a file that imports them, a bare round($x) calls phibble’s expression helper. Write \round($x) for PHP’s function.

Load

DataFrame::fromCsv() reads a CSV file, or a URL, and guesses each column’s type. Here it reads the Palmer penguins data, whose rownames column holds the row numbers the table had in R. Reading and writing data covers the options, JSON, and databases.

        .'main/csv/penguins.csv'

tibble() builds a data frame column by column:

  • A list gives one value per row, and a single value is repeated.
  • A closure receives the columns built so far.

These values are the first four penguins in the data:

$penguins = tibble(
    species: 'Adelie',
    island: ['Torgersen', 'Torgersen', 'Torgersen', 'Torgersen'],
    body_mass_g: [3750, 3800, 3250, null],
    heavy: fn (DataFrame $t) => array_map(
        fn ($m) => $m === null ? null : $m >= 3500,
        $t['body_mass_g'],
    ),
);

echo $penguins;
# A tibble: 4 × 4
  species island    body_mass_g heavy

2 Adelie  Torgersen        3800 TRUE

DataFrame::fromRows() takes a list of associative arrays, and keys missing from a row are NA. DataFrame::fromColumns() takes an array of columns, or an object with a toColumns() method such as phit’s tidy() result, and accepts explicit types.

$rows = DataFrame::fromRows([
    ['species' => 'Adelie', 'island' => 'Torgersen', 'body_mass_g' => 3750],
    ['species' => 'Adelie', 'island' => 'Torgersen'],
]);
$cols = DataFrame::fromColumns(
    ['species' => ['Adelie', 'Gentoo'], 'island' => ['Torgersen', 'Biscoe']],
    types: ['species' => 'factor'],
);

echo $rows, "\n\n", $cols;
# A tibble: 2 × 3
  species island    body_mass_g
  <chr>   <chr>           <int>
1 Adelie  Torgersen        3750
2 Adelie  Torgersen          NA

# A tibble: 2 × 2
  species island   
  <fct>   <chr>    
1 Adelie  Torgersen
2 Gentoo  Biscoe

Inspect

echo $df prints a data frame as tibble does:

  • The header gives the size, and each column shows its type.
  • More than 20 rows print the first 10.
  • Numbers show three significant digits.
  • NA prints as NA, or <NA> in text columns.

format(n: 30, width: 120) prints more rows or a wider table. glimpse() gives one line per column, which suits wide data frames:

$penguins = DataFrame::fromCsv(
    'https://raw.githubusercontent.com/phpstats/datasets/'
        .'main/csv/penguins.csv'
);

echo $penguins->glimpse();

Each column has one type from the Phibble\Type enum, inferred from the values, and PHP null is NA in every type. Types covers inference, casts, and factors.

Read values:

  • $df->name, $df['name'], and $df->column('name') return a column as a PHP list.
  • Rows are Phibble\Row objects, which read values as properties or array keys. Iterating a data frame yields its rows.
  • An unknown column name throws Phibble\Exception\ColumnNotFound. Names are never matched partially.
$df = tibble(x: [1, 2, 3], y: ['a', 'b', 'c']);

var_dump($df->x === $df['x']);
echo json_encode($df->column('y')), "\n";

$row = $df->row(1);
echo $row->x, ' ', $row['y'], "\n";

foreach ($df as $i => $row) {
    echo "{$i}: {$row->y}\n";
}

try {
    $df->z;
} catch (Phibble\Exception\ColumnNotFound $e) {
    echo $e->getMessage(), "\n";
}
bool(true)
["a","b","c"]
2 b
0: a
1: b
2: c
Column 'z' not found. Available columns: x, y.

Transform

Data frames have dplyr’s functions as methods: select(), filter(), mutate(), rename(), arrange(), groupBy(), summarize(), distinct(), slice(), head(), and join(). Each returns a new data frame, and the original never changes. Functions and methods lists them all:

$df = tibble(x: [1, 2, 3]);
$doubled = $df->mutate(['x' => col('x')->mul(2)]);

echo json_encode($df->x), ' ', json_encode($doubled->x), "\n";
[1,2,3] [2,4,6]

filter() and mutate() accept a row closure, which receives a Row. arrange() takes column names, or [name, 'desc'] pairs.

$penguins = DataFrame::fromCsv(
    'https://raw.githubusercontent.com/phpstats/datasets/'
        .'main/csv/penguins.csv'
);

$heavy = $penguins
    ->select(['species', 'island', 'body_mass_g', 'year'])
    ->filter(fn ($r) => $r->body_mass_g > 5500)
    ->mutate(['kg' => fn ($r) => $r->body_mass_g / 1000])
    ->arrange([['body_mass_g', 'desc']])
    ->head(5);

echo $heavy;
# A tibble: 5 × 5
  species island body_mass_g  year    kg
  <chr>   <chr>        <int> <int> <dbl>
1 Gentoo  Biscoe        6300  2007  6.3 
2 Gentoo  Biscoe        6050  2007  6.05
3 Gentoo  Biscoe        6000  2008  6   
4 Gentoo  Biscoe        6000  2009  6   
5 Gentoo  Biscoe        5950  2008  5.95

The same methods accept expressions built with col() and the helper functions. Expressions run a whole column at a time, and SQL and Polars tables can translate them.

$penguins = DataFrame::fromCsv(
    'https://raw.githubusercontent.com/phpstats/datasets/'
        .'main/csv/penguins.csv'
);

$heavy = $penguins
    ->select(['species', 'island', 'body_mass_g', 'year'])
    ->filter(col('body_mass_g')->gt(5500))
    ->mutate(['kg' => col('body_mass_g')->div(1000)])
    ->arrange([desc(col('body_mass_g'))])
    ->head(5);

echo $heavy;
# A tibble: 5 × 5
  species island body_mass_g  year    kg
  <chr>   <chr>        <int> <int> <dbl>
1 Gentoo  Biscoe        6300  2007  6.3 
2 Gentoo  Biscoe        6050  2007  6.05
3 Gentoo  Biscoe        6000  2008  6   
4 Gentoo  Biscoe        6000  2009  6

PHP null is a missing value. Arithmetic with it gives null, and an aggregate over a column that holds it gives null unless na_rm: true:

$penguins = DataFrame::fromCsv(
    'https://raw.githubusercontent.com/phpstats/datasets/'
        .'main/csv/penguins.csv'
)->head(4)->select(['species', 'body_mass_g']);

echo $penguins->mutate([
    'mass_kg' => col('body_mass_g')->div(1000),
]), "\n";
echo $penguins->summarize([
    'mean' => mean(col('body_mass_g')),
    'mean_known' => mean(col('body_mass_g'), na_rm: true),
]);
# A tibble: 4 × 3
  species body_mass_g mass_kg
  <chr>         <int>   <dbl>
1 Adelie         3750    3.75
2 Adelie         3800    3.8 
3 Adelie         3250    3.25
4 Adelie           NA   NA   
# A tibble: 1 × 2
   mean mean_known
  <dbl>      <dbl>
1    NA       3600

Summarize

groupBy() records grouping columns, and summarize() (or summarise()) returns one row per group:

  • Groups are sorted, with NA last, as in dplyr.
  • With several grouping columns, the result keeps all but the last.
  • In a grouped data frame, filter() and mutate() work within each group, and an aggregate in mutate() repeats for each row of its group.
  • A row closure receives the row’s group as its second argument: fn (Row $r, DataFrame $group) => ....
$penguins = DataFrame::fromCsv(
    'https://raw.githubusercontent.com/phpstats/datasets/'
        .'main/csv/penguins.csv'
)
    ->dropNa(['body_mass_g']);

$centered = $penguins
    ->groupBy(['species'])
    ->mutate([
        'vs_species' => col('body_mass_g')
            ->sub(mean(col('body_mass_g'))),
    ])
    ->select(['species', 'body_mass_g', 'vs_species'])
    ->head(4);

echo $centered;
# A tibble: 4 × 3
# Groups:   species [1]
  species body_mass_g vs_species
  <chr>         <int>      <dbl>
1 Adelie         3750       49.3
2 Adelie         3800       99.3
3 Adelie         3250     -451. 
4 Adelie         3450     -251.

Groups are the combinations that occur in the data. groupBy($names, drop: false), like dplyr’s .drop = FALSE, also gives a factor’s empty levels a group, where n() and sum() are 0:

$penguins = DataFrame::fromCsv(
    'https://raw.githubusercontent.com/phpstats/datasets/'
        .'main/csv/penguins.csv'
)
    ->asFactor('species')
    ->filter(col('species')->ne('Chinstrap'));

echo $penguins
    ->groupBy(['species'], drop: false)
    ->summarize(['n' => n()]);
# A tibble: 3 × 2
  species       n
  <fct>     <int>
1 Adelie      152
2 Chinstrap     0
3 Gentoo      124

Combine

distinct() keeps the first row of each combination of the given columns. join() takes the other table, the keys, and the type: inner, left, right, full, semi, anti, or cross. A pair such as ['origin', 'faa'] joins keys with different names. Joins follow dplyr 1.1, and NA keys match each other. Here each airport in nycflights13’s weather data gets its name, position, and altitude from the airports table:

$data = 'https://raw.githubusercontent.com/phpstats/datasets/main/csv';
$weather = DataFrame::fromCsv("{$data}/weather.csv");
$airports = DataFrame::fromCsv("{$data}/airports.csv");

$stations = $weather
    ->distinct(['origin'])
    ->join($airports, [['origin', 'faa']], 'left')
    ->select(['origin', 'name', 'lat', 'lon', 'alt']);

echo $stations;
# A tibble: 3 × 5
  origin name                  lat   lon   alt
  <chr>  <chr>               <dbl> <dbl> <int>
1 EWR    Newark Liberty Intl  40.7 -74.2    18
2 JFK    John F Kennedy Intl  40.6 -73.8    13
3 LGA    La Guardia           40.8 -73.9    22

A condition can also compare columns, as in dplyr’s join_by(). Here each hour with Newark departures on 1 January 2013 gets the latest weather reading at or before it. Newark has no reading for 17:00 UTC, so that hour takes the 16:00 reading:

$data = 'https://raw.githubusercontent.com/phpstats/datasets/main/csv';
$flights = DataFrame::fromCsv("{$data}/flights.csv", nMax: 1000)
    ->filter(col('origin')->eq('EWR')->and(col('time_hour')->between(
        ymd_hms('2013-01-01 16:00:00'),
        ymd_hms('2013-01-01 18:00:00'),
    )))
    ->distinct(['origin', 'time_hour']);
$weather = DataFrame::fromCsv("{$data}/weather.csv")
    ->select(['origin', 'time_hour', 'temp', 'wind_speed'])
    ->rename(['observed' => 'time_hour']);

echo $flights->join(
    $weather,
    ['origin', ['closest', 'time_hour', '>=', 'observed']],
    'left',
);
# A tibble: 3 × 5
  origin time_hour           observed             temp wind_speed
  <chr>  <dttm>              <dttm>              <dbl>      <dbl>
1 EWR    2013-01-01 16:00:00 2013-01-01 16:00:00  41         15.0
2 EWR    2013-01-01 17:00:00 2013-01-01 16:00:00  41         15.0
3 EWR    2013-01-01 18:00:00 2013-01-01 18:00:00  39.2       16.1

The Table contract lists the join conditions and options.

Output

  • toRows() returns a list of associative arrays, and toColumns() an array of columns.
  • writeCsv($path) and toCsv() write CSV as readr’s write_csv() does.
  • toJson() writes records, or columns with toJson('columns').

Reading and writing data covers the formats.

Method chains and the pipe operator

Methods chain on PHP 8.3, 8.4, and 8.5. On PHP 8.5, |> with arrow functions runs the same pipeline. phplyr provides functions that work with |> without arrow functions.

  • PHP 8.5+
  • PHP 8.3–8.4
$penguins = DataFrame::fromCsv(
    'https://raw.githubusercontent.com/phpstats/datasets/'
        .'main/csv/penguins.csv'
);

$counts = $penguins |>
    (fn (DataFrame $f) => $f->groupBy(['island'])) |>
    (fn (DataFrame $f) => $f->summarize(['n' => n()])) |>
    (fn (DataFrame $f) => $f->arrange([desc(col('n'))]));

echo $counts;
$penguins = DataFrame::fromCsv(
    'https://raw.githubusercontent.com/phpstats/datasets/'
        .'main/csv/penguins.csv'
);

$counts = $penguins
    ->groupBy(['island'])
    ->summarize(['n' => n()])
    ->arrange([desc(col('n'))]);

echo $counts;
# A tibble: 3 × 2
  island        n
  <chr>     <int>
1 Biscoe      168
2 Dream       124
3 Torgersen    52
